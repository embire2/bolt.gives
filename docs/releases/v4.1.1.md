# bolt.gives v4.1.1

15 September 2026. This patch includes the entire [v4.1.0 reliability release](v4.1.0.md).
The original tag is preserved rather than silently replaced after publication.

## Corrections

Fleet acceptance reproduced HTTP 503 from Cloudflare readiness while the actual
runtime and generated Preview were working. Workers rejects `redirect: "error"`.
Readiness now uses `manual`, rejects redirects without following them, and still
requires a healthy runtime with matching application version and protocol within
three seconds. The failure and correction were exercised in the actual Workers
runtime, not only a Node mock.

The release gate also incorrectly matched the words "server error" in changelog
prose describing an old fix. Error detection now checks rendered error-page
titles, headings and disclosure labels, while preserving HTTP, current-version,
screenshot and actual error-page checks. Regression tests cover the previously
failing prose and real error surfaces.

## Install

Download the Linux or PowerShell installer and checksums attached to this release.
The Linux archive is public server source, not the private native Windows client.

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
bash install-bolt-gives.sh --branch v4.1.1
```

Existing installations must retain their current install directory and domains.
Secrets and customer data are preserved by the guarded installer. PowerShell
bootstraps the server through WSL; the native Windows release remains independent.

Production Stripe is enabled, but the operator's real paid transaction remains
deliberately uncharged by automation. See the [roadmap](../../ROADMAP.md) for
remaining platform/provider acceptance and independent Windows work.
