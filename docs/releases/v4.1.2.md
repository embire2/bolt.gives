# v4.1.2: Hosted Coding and Account Reliability

The managed FREE model is **GLM 5.3 Flash** through OpenRouter
`z-ai/glm-5.3-flash`. Existing FREE selections move to the current model without
discarding their conversation, source files or runtime identity. Personal
OpenRouter and MagnetAPI connections remain separate bring-your-own-key paths.

## Included Fixes

- Authorized isolated Preview asset reads wait through a cleared-port restart
  handoff without bypassing ownership. Project history waits for an existing
  runtime start rather than immediately rerunning setup, with bounded waiting
  and cancellation on navigation. Idle-history E2E requires settled readiness.
- Admin fleet status reads an atomic snapshot without waiting for a deployment
  lock or rewriting assignments. Hostile-origin admin mutations are rejected
  before rendering on direct production and managed domains alike.
- FREE accounts receive **20 API credits per GMT+2 day**, calibrated to roughly
  20 minutes of server-measured active generation. Idle editing is not charged.
  Usage resets at 00:00 GMT+2. Exhaustion offers an upgrade, a personal provider
  key, or the next reset; Custom Domain billing allowances are unchanged.
- Quota writes are serialized and repeated run records are deduplicated. The
  prior ledger is migrated without throwing away consumed coding time.
- Managed instance creation requires the signed-in account. The default limit
  is one instance per account, not one browser cookie. An authenticated operator
  can turn this policy on or off in `/admin`; existing instances are preserved.
- `/admin` works on configured client domains using the protected control-plane
  backend. Cross-origin mutations are rejected. Admin sessions expire and are
  invalidated by password changes; production requires a private signing secret.
- Public production login refuses an unchanged bootstrap admin password. Existing
  passwords are preserved. Registry reads no longer rewrite account records, and
  unreadable/corrupt registries fail closed rather than resetting credentials.
- Custom Cloudflare domains preserve the configured FREE streaming relay and
  collaboration WebSocket backend, without bypassing caller CSRF checks.
- Outgoing mail supports a sender name and Reply-To consistently, including
  emailed login codes. Port 587 requires STARTTLS; connections have deadlines
  and protected credential changes invalidate the cached transport.
- Registration carries the visitor's rate-limit identity to the runtime instead
  of sharing one backend bucket. Instance setup recognizes the native onboarding
  dialog and shows the current GLM allowance.
- Repair health polling remains authorized while a project's dev server changes
  ports; isolated redirects retain their cross-origin embedding permission.
- Chat transfers the native response to one bounded consumer and immediately
  cancels the unused branch. HTTPS completion, cancellation and failures remain
  observable without a duplicate background reader. Headers identify AI SDK v1
  framing correctly; normal HTTP protocol negotiation remains enabled.

## Installation and Upgrades

Use the Linux source archive and pinned Linux/PowerShell installers attached to
the [release](https://github.com/embire2/bolt.gives/releases/tag/v4.1.2).
The PowerShell script bootstraps the server through WSL; it is not a replacement
native desktop application. Existing secrets and customer workspaces must be
preserved. See the [installation instructions](../../README.md#install-on-ubuntu).

Self-host operators who fund FREE set `BOLT_FREE_OPENROUTER_API_KEY` privately.
No shared key is included in source or generated apps. Configure
`BOLT_TENANT_ADMIN_COOKIE_SECRET` with a random private value; the installer
generates it for new installs. Hosted Cloudflare instances relay to the backend
instead of receiving either secret. Operator policy defaults to
`BOLT_MANAGED_INSTANCE_SINGLE_PER_USER=true`.

An unchanged bootstrap admin password must be replaced through the server-local
runtime's `POST /runtime/tenant-admin/admin/password` endpoint before public
admin login. Supply `currentPassword` and `nextPassword` privately; never expose
that loopback endpoint or place passwords in shell history. Existing configured
administrators keep their passwords.

## Acceptance

The isolated Cloudflare alpha passed a real GLM prompt, visible Preview,
same-project follow-up, saved-history reload and public publishing in 160 seconds.
The public app remained available after stopping its coding runtime. Both model
streams completed, with no fatal browser or network errors. The suite passed
1,522 tests (nine skipped), plus all six real template Preview smokes.
See the [dated evidence and limits](../quality/2026-09-20-v4.1.2-acceptance.md).

## Validation Boundaries

The web/server release has an independent validation path from native Windows.
Supabase replacement/error-handling work, account-specific MagnetAPI behavior,
Windows reboot-resume and a real paid Stripe transaction remain explicit
[roadmap items](../../ROADMAP.md). Automated billing checks do not charge cards.
Acceptance evidence is recorded in the release's quality report, not inferred
from a successful deployment API response.
